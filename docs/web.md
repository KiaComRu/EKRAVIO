# Веб-панель Экравио

Панель размещена на SpaceWeb в `geekparts/kiacom/public_html/EKRAVIO`. [Открыть Экравио](https://ekravio.kiacom.ru/).

После открытия панели подключите MediaMTX. В разделах «Экраны» и «Архив» доступны видео выбранного потока и записи, полученные с этого сервера.

Через «Подключить сервер» укажите HTTPS-адреса WebRTC и архива MediaMTX, путь потока (`stage0` в собранном прототипе) и учётную запись `viewer`. Пароль передаётся по HTTPS вашему медиасерверу и хранится в памяти вкладки. Панель запрашивает один поток и список записей с текущего медиасервера. Учёт активности в режиме сервера требует отдельного API, который ещё предстоит реализовать.

## Подключение к установленному серверу

1. Подготовьте MediaMTX с TLS-сертификатом, которому доверяет браузер. Для работы на другом компьютере следуйте разделу о LAN. [Инструкция по установке сервера](install-windows.md).
2. В `%ProgramData%\Ekravio\Server\mediamtx.yml` добавьте `https://ekravio.kiacom.ru` в оба списка CORS. Сохраните существующие значения `webrtcAllowOrigins` и `playbackAllowOrigins` и перезапустите `Ekravio.Media`.
3. Запустите агент. В панели Экравио подключите MediaMTX, затем откройте экран. Для архива выберите дату по часовому поясу браузера.

Браузеру нужны сетевой доступ к HTTPS-адресам MediaMTX и подходящий маршрут ICE для WebRTC. Просмотр записи через панель загружает MP4 размером до 96 МБ. [Просмотр по WebRTC](https://mediamtx.org/docs/read/webrtc), [формат архива](https://mediamtx.org/docs/features/playback).

## Локальный запуск

```powershell
python -m http.server 18476 --bind 127.0.0.1 --directory web
```

Локальный адрес — `http://127.0.0.1:18476/`. Для локального прогона в CORS MediaMTX добавьте `http://127.0.0.1:18476`. В этом режиме принимаются HTTP-адреса MediaMTX на loopback.

## Размещение

В папке `web` лежит готовый к публикации комплект статических файлов. В общем `.htaccess` SpaceWeb правило для хоста `ekravio.kiacom.ru` направляет запросы в `/EKRAVIO/`. Существующее правило перенаправления HTTP на HTTPS действует и для этого поддомена.
