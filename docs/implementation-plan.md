# План реализации Экравио

Основа — [ТЗ 1.3](Ekravio_TZ_for_Codex.md), разделы 13–15. Для пилота принимаем 20 ПК, до двух мониторов на устройство, три одновременных наблюдателя, видео за 7 суток и активность за 30 суток. Отображение времени по умолчанию в `Europe/Moscow`, храним время в UTC. Порог отсутствия ввода по умолчанию 60 секунд. Запись и учёт ввода имеют отдельные состояния и расписания.

## Матрица серверов

- Windows 10 22H2 и Windows 11 x64 начиная с Home. Нативный запуск без Docker, WSL, IIS и Hyper-V. Начать испытания с Windows 10 Home.
- Windows Server 2019, 2022 и 2025 x64. Отдельная проверка Server Core и работы служб без входа пользователя.
- Ubuntu 24.04 LTS и Debian 12/13 x64 с `systemd`. Дополнительный прогон Docker Compose.

Статус конкретных ОС, версий средств удалённого управления и тестов фиксируется в [протоколе этапа 0](prototype.md). Версии для сборки MVP закрепляются после испытаний. Совместимость с Windows 10 Home и поддержка этой ОС поставщиками зависимостей проверяются отдельно.
